# Data-Analyst-30-Days-Challenge-Sep-2026

Welcome to my Codebasics "Your First 30 Days as a Data Analyst" Challenge project. This repository documents a 30-day business-reasoning series, working as a Data Analyst at AtliQ Café and resolving day-to-day requests from my manager, Ritu. Each day takes one business question, works through the ambiguity hiding inside it, and documents the resolution along with the lesson it surfaced.

## Project Description

This repository contains the daily body of work from the Codebasics "Your First 30 Days as a Data Analyst" challenge.

Each day starts with one request landing on my desk at AtliQ Café, usually from my manager Ritu or a colleague from another team. The request looks simple on the surface, but resolving it cleanly means spotting the ambiguous word or number hiding inside it first. Each day's PDF documents the request, the ambiguity, the verdict, and the lesson it left behind.

## Key Features

- *Ambiguity Resolution* - spotting the word or number in a request that has more than one valid reading
- *Stakeholder-Ready Verdicts* - a short, clear decision written for the person who actually asked, not a technical audience
- *Business-First Reasoning* - business question first, tool second, throughout all 30 days
- *Daily Documentation* - one request, one resolution, one lesson, documented each day
